# Personal Finance Manager

A desktop-based Personal Finance Manager developed using Java Swing, MySQL, and JDBC. The application helps users manage income and expenses, categorize transactions, and analyze financial data through interactive charts and reports.

## Features

- User Authentication
- Income Tracking
- Expense Tracking
- Transaction Management
- Category Management
- Monthly Financial Reports
- Pie Chart Analysis
- Bar Chart Analysis
- MySQL Database Integration
- User-Friendly Graphical Interface

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Maven
- DAO Design Pattern

## Project Structure

## Database Setup

1. Install MySQL Server.
2. Create a database named:

```sql
expense_tracker_tsec
```

3. Execute the SQL schema file provided with the project.
4. Update the database credentials in:

```java
DBConnection.java
```

5. Run the application.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/jishant30/Personal_Finance_Manager.git
```

2. Open the project in NetBeans.
3. Configure MySQL database credentials.
4. Build the project using Maven.
5. Run the application.
